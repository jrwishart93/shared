# Slideshow photos

Drop optimised slideshow images in this folder when you want the `/slideshow` page to pick them up automatically at build/start time.

Recommended format:

```text
/public/photos
  001.jpg
  002.jpg
  003.jpg
```

Keep images at or below 1920px wide for best performance on older iPads. Supported extensions are `.jpg`, `.jpeg`, `.png`, `.webp`, and `.gif`.
